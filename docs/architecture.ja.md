# アーキテクチャ

`irodori-migration` は実行を伴わないプランニング用クレートです。

プラン、SQL、プレビュー、マニフェスト、エクスポートストリームを生成します。ホストアプリケーションは接続、認証情報、スケジューリング、承認、実行を管理します。

## フロー

1. ソース、ターゲット、キー、カラムを記述します。
2. プランを生成します。
3. 破壊的変更をレビューします。
4. カウントとチェックサムを比較します。
5. バケットごとに不一致を絞り込みます。
6. 必要な箇所だけ行の差分を取ります。
7. ホストに承認された作業を実行させます。

## モジュール

- `plan`: マイグレーションプランとSQL。
- `canonical`: エンジン間共通の値レンダリング。
- `checksum`: チャンク化されたチェックサムとマニフェスト。
- `schema`: スキーマスナップショットと差分。
- `recipe`: ドライランプレビュー。
- `rollout`: ランブックの拡張・縮小。
- `io`: 表形式のインポート/エクスポート。
- `export`: 進捗とキャンセルのラッパー。
- `dialect`: 最小限のSQLヘルパー。
